# Vireqo locked homepage reference

This project uses the light premium motion homepage shown in the supplied reference video.

Locked homepage behavior:
- Rounded floating navigation
- Editorial left-side hero headline
- Animated AI concierge and pipeline cards
- Type-on chat sequence, counters, chart drawing, floating activity and meeting signals
- Journey, industry demo, modules, outcome metrics and integration sections
- Dark green final CTA with animated orbit
- Slim left-edge chatbot launcher that stays accessible while scrolling and expands on hover

Do not replace `frontend/components/Hero.tsx` with `HeroV4.tsx`, and do not replace the homepage with the older MVP layout.
